### 🔹 **Long Answer / Descriptive Questions**

1. Explain all **seven layers of the OSI model** with their respective protocols and functions.
2. Compare the OSI and TCP/IP models in detail.

| **Feature**                   | **OSI Model**                                                               | **TCP/IP Model**                                 |
| ----------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------ |
| **Full Form**                 | Open Systems Interconnection                                                | Transmission Control Protocol/Internet Protocol  |
| **Number of Layers**          | 7                                                                           | 4 (or sometimes considered 5)                    |
| **Layers**                    | Application, Presentation, Session, Transport, Network, Data Link, Physical | Application, Transport, Internet, Network Access |
| **Developed By**              | ISO (International Standards Organization)                                  | DARPA (U.S. Department of Defense)               |
| **Function**                  | Conceptual model for understanding networks                                 | Practical model used in real networking          |
| **Protocol Specification**    | Generic, does not specify protocols                                         | Specific protocols are defined (TCP, IP, etc.)   |
| **Usage**                     | Mostly for teaching and reference                                           | Used in real-world internet communication        |
| **Layer Separation**          | Strict and clear separation                                                 | Loose and overlapping layers                     |
| **Model Type**                | Theoretical                                                                 | Practical/Implementation-based                   |
| **Transport Layer Protocols** | TCP, UDP, etc. (as examples)                                                | TCP, UDP                                         |

6. What is the difference between connection-oriented and connectionless communication? Give examples.

| **Feature**           | **Connection-Oriented Communication**         | **Connectionless Communication**             |
| --------------------- | --------------------------------------------- | -------------------------------------------- |
| **Definition**        | Establishes a connection before data transfer | Sends data without establishing a connection |
| **Setup**             | Required (handshake process)                  | Not required                                 |
| **Reliability**       | Reliable (ensures delivery, error checking)   | Unreliable (no guarantee of delivery)        |
| **Overhead**          | Higher (due to connection setup and tracking) | Lower (no setup or tracking)                 |
| **Speed**             | Slower due to setup and acknowledgment        | Faster due to no connection overhead         |
| **Example Protocols** | TCP (Transmission Control Protocol)           | UDP (User Datagram Protocol)                 |
| **Use Cases**         | File transfer, web browsing, emails           | Live video/audio streaming, online gaming    |

### **Examples:**

* **Connection-Oriented**:

  * Browsing a website (HTTP over TCP)
  * Sending emails (SMTP over TCP)

* **Connectionless**:

  * Watching a live stream (uses UDP)
  * Voice over IP (VoIP)

7. Write short notes on:
   a) ARP
      Address Resolution Protocol or ARP is a communication protocol used to find the MAC/ physical address of a device from its ip address.
      This protocol is used when a device wants to communicate with another device on a LAN or ethernet.

      Working of ARP:
      1. **Sender knows the IP address** of the device it wants to reach.
      2. **IP asks ARP** to find out the target's physical (MAC) address using its IP.
      3. **ARP creates a request** with the sender’s MAC, sender’s IP, and the target’s IP.
      4. **The request is sent as a broadcast** to all devices on the network.
      5. **All devices receive it**, but only the target device responds because it matches the IP.
      6. **The target sends back a reply** with its MAC address (as a unicast reply).
      7. **Sender gets the reply**, learns the target’s MAC, and now sends the actual data in a unicast frame.
